# 工作台界面审查

本次面向物流操作和调度人员，优先支持异常审核与任务闭环。证据来自修改前的 HTML、CSS 和交互源码；浏览器验证另见 UI_QA.md。

| 优先级 | 层级 | 问题与证据 | 置信度 | 修改与验收 |
| --- | --- | --- | --- | --- |
| P1 | Required | 详情隐藏后仍保留可聚焦控件；编辑窗口没有 Tab 范围管理，Escape 同时关闭两层 | 高 | inert、焦点范围、逐层关闭与返回；键盘验证 |
| P1 | Contextual | 首屏四张指标卡和四项运营指标挤占异常队列；其中本周关闭数不来自当前队列 | 高 | 只保留队列内计算的三项摘要，集中标明固定样例 |
| P2 | Contextual | 多个标签字号为 .66–.76rem，导航与次级文字对比偏弱 | 高 | 统一至少 .8125rem 标签、加强对比；实际计算样式检查 |
| P2 | Contextual | 手机详情仍为两列字段；固定底栏高度无法容纳文字放大 | 高 | 单列详情、可自然增高的导航；320–1440px 与文字放大验证 |
| P3 | Preference | 统一浅色内容、深色导航和青绿强调 | 高 | 遵循已确认视觉方向，不作为标准违规 |

保留五类角色、原策略、模拟数据及任务状态；不连接真实系统。
